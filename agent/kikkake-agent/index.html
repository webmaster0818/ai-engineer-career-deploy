キッカケエージェントに関するQ&A

Q

キッカケエージェントの評判は良いですか？

A

当サイトでは利用者の口コミを独自に集めていないため、公的データと公式の公表値で確認できる範囲をご説明します。厚生労働省の人材サービス総合サイトでは、就職者589人（うち無期524人）、無期のうち6か月以内の離職者8人（約1.5%）が掲載されています（令和8年11月1日現在）。公式サイトでは、2025年の入社者465人のうち半年以内の退職者7人（短期離職率1.51%）を公表しています。

Q

キッカケエージェントは未経験でも利用できますか？

A

公式サイトの比較表では、未経験者への対応を「×」と表示しています。ITエンジニアとしての実務経験がある方向けのサービスと考えるのが適切です。未経験からAI・IT職を目指す方は、未経験者向けの支援を掲載している「未経験からAI転職におすすめ転職エージェントランキング」もご覧ください。

Q

キッカケエージェントにAIエンジニアの求人はありますか？

A

あります。公式の求人検索で、フリーワード「機械学習」が2,169件、「生成AI」が3,330件、「データサイエンティスト」が1,392件でした（2026年11月15日）。本文に語を含む求人の件数のため、AI職そのものの求人数とは異なります。

Q

キッカケエージェントは応募数が少ないと聞きましたが本当ですか？

A

公式サイトに「30～40社の同時応募はいたしません」と記載されており、一人当たりの書類応募数は12.14件（2025年4月〜2026年4月の実績）と公表されています。応募先を絞り込む方針です。

Q

キッカケエージェントの運営会社はどこですか？

A

株式会社キッカケクリエイション（2020年3月26日設立、東京都渋谷区）です。有料職業紹介事業の許可番号は13-ユ-312698で、厚生労働省のサイトでも確認できます。
