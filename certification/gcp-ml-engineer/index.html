Google Cloud ML Engineer

Google Cloud Professional Machine Learning Engineer

Google Cloud Professional Machine Learning Engineerは、Google Cloudの機能と従来のMLの知識を使ってAIソリューションを構築・評価・本番運用・最適化する人を対象にした、Google CloudのProfessional認定です。試験は2時間・50〜60問・200米ドル（税別）で、認定の有効期間は2年です。試験は Vertex AI から Gemini Enterprise Agent Platform への移行に合わせて更新されています（2026年10月26日 Google Cloud公式で確認）。

最終更新: 2026年10月26日

試験の基本情報

主催Google Cloud
レベルProfessional（上級）
試験形式多肢選択（択一・複数選択）50〜60問・2時間。英語/日本語。オンライン監督受験またはテストセンター受験（Pearson VUE）。コーディング力は直接問われない（PythonとSQLの最低限の知識があればコードを含む問題を読める、と試験ガイドに記載）
受験料200米ドル(該当地域では別途税)
実施頻度通年(随時受験)
合格率の目安非公表
勉強時間の目安公式は学習時間を示していない（推奨経験: 業界経験3年以上、うちGoogle Cloudでのソリューション設計・管理1年以上）

よくある質問

Google Cloud の ML 認定（Professional Machine Learning Engineer）の試験時間・受験料・形式は？+
試験時間は2時間、登録料は200米ドル（該当地域では別途税）、形式は50〜60問の多肢選択（択一・複数選択）です。言語は英語と日本語で、オンライン監督受験かテストセンター受験を選べます。受験の前提条件はありません（2026年10月26日 Google Cloud公式の試験ページで確認）。
有効期限と更新（再認定）の方法は？+
Professional認定の有効期間は取得日から2年です。更新は有効期限の60日前から受けられ、更新すると有効期限に2年が加わります。有効期限から30日以内であれば更新が可能です。短縮版の更新試験はProfessional Cloud ArchitectとProfessional Data Engineerが対象で、その他のProfessional認定は「近日提供予定」とされています（Google Cloud 認定ヘルプ、2026年10月26日確認）。
出題範囲と配点は？+
2026年6月1日版の試験ガイドでは、ローコードAIソリューションの設計（約13%）、チーム内外で連携したデータとモデルの管理（約16%）、プロトタイプのMLモデルへのスケール（約21%）、モデルのサービングとスケーリング（約20%）、MLパイプラインの自動化とオーケストレーション（約18%）、AIソリューションのモニタリング（約13%）の6分野です。BigQuery MLやAutoMLでのモデル開発、Geminiモデルのチューニングや評価も含まれます。
Vertex AI の名称変更で試験は変わりましたか？+
Google Cloud公式の試験ページによると、この試験は Vertex AI から Gemini Enterprise Agent Platform への移行と、Google Cloud のデータ分析スタックの更新に合わせて更新され、Google Cloud ネイティブのソリューションを優先する内容になっています。試験で使われるプロダクト名は新しい試験ガイドで確認するよう案内されています（2026年10月26日確認）。
不合格だった場合、いつ再受験できますか？+
Google Cloud の試験規約では、AssociateとProfessionalの試験は2年間で最大4回まで受験できます。1回目に不合格の場合は14日後、2回目の不合格後は60日後、3回目の不合格後は365日後から再受験できます（Exam Terms & Conditions、2026年10月26日確認）。結果の確定には7〜10日かかる場合があります（Google Cloud 認定 FAQ）。
未経験でも受験できますか？+
受験の前提条件はありません。公式の推奨経験は、Google Cloudでのソリューションの設計と管理1年以上を含む、3年以上の業界経験です。試験はコーディング力を直接は問いませんが、PythonとSQLの最低限の知識があればコードを含む問題を読み解ける、と試験ガイドに記載されています。
