AWS認定 機械学習エンジニア – アソシエイト

AWS Certified Machine Learning Engineer - Associate (MLA-C01)

AWS Certified Machine Learning Engineer – Associateは、本番環境に機械学習を実装して運用可能にする技術的能力を実証するAssociateレベルの認定資格です。試験は更新中で、更新版のMLA-C02はベータ版が英語で提供されています。日本語の現行試験（MLA-C01）は、MLA-C02の一般提供まで受験できます。従来のAWS Certified Machine Learning – Specialtyは2026年3月31日を最終受験日として廃止され、AWS公式は同資格のページで機械学習の認定として本資格を案内しています。

最終更新: 2026年10月19日

試験の基本情報

主催Amazon Web Services（AWS）
レベル中級(Associate)
試験形式現行のMLA-C01は全65問(採点対象50問＋採点対象外15問)・130分。択一選択・複数選択・並べ替え・組み合わせ・ケーススタディ。テストセンターまたはオンライン監督受験。100〜1,000点の換算スコアで合格720点。更新版MLA-C02のベータ版は85問・170分(英語のみ)
受験料150米ドル／日本円は20,000円(AWS公式の試験料金。税が適用される場合あり。円建て価格は為替レートを反映して少なくとも毎年1回5月に改定)。MLA-C02ベータ版は75米ドル
実施頻度通年(随時受験)
合格率の目安非公表(合格ライン720/1000)
勉強時間の目安公式推奨: SageMaker等でのMLエンジニアリング経験1年以上＋関連職務経験1年以上

受験をおすすめする方

  • ●SageMaker等でMLパイプラインを構築・運用するMLエンジニア
  • ●MLOps・ML基盤を担うバックエンド/DevOpsエンジニア・データエンジニア
  • ●ML Specialtyの廃止後に、AWSの機械学習の認定を検討している人

主な出題範囲

第1分野: 機械学習(ML)のためのデータ準備（28%）第2分野: MLモデルの開発（26%）第3分野: MLワークフローのデプロイとオーケストレーション（22%）第4分野: MLソリューションのモニタリング、保守、セキュリティ（24%）

よくある質問

MLA-C01の試験形式と合格点を教えてください。+
現行のMLA-C01は全65問(採点対象50問＋採点対象外15問)・130分で、択一選択・複数選択に加えて並べ替え・組み合わせ・ケーススタディ形式が含まれます。100〜1,000点の換算スコアで合格は720点です(MLA-C01公式試験ガイドで確認)。
受験料はいくらですか？+
150米ドルです。日本円建ては20,000円で、税が適用される場合があります。円建て価格は為替レートを反映して少なくとも毎年1回5月に改定されます。AWS認定を1つ取得すると、次回のAWS認定試験が50%割引になります。更新版MLA-C02のベータ版は75米ドルです(AWS公式、2026年10月19日確認)。
廃止されたML Specialtyとの違いは？+
AWS Certified Machine Learning – Specialty(MLS-C01)は2026年3月31日を最終受験日として廃止されました。取得済みの認定は取得日から3年間有効です。AWS公式は同資格のページで、機械学習の認定としてMachine Learning Engineer – Associateを案内しています。レベルはSpecialtyに対してAssociateで、受験料はSpecialtyの300米ドルに対して150米ドルです。
MLA-C01とMLA-C02の違い・移行時期を教えてください。+
AWS公式によると、本試験は更新中です。更新版MLA-C02のベータ版は2026年9月1日に登録受付が始まり、9月29日から英語のみで提供されています(85問・170分・75米ドル)。英語のMLA-C01は2026年9月28日で受験を終了しました。日本語・韓国語・簡体字中国語のMLA-C01は、MLA-C02の一般提供まで受験できます。一般提供の開始日は未定です。MLA-C02では生成AIの実装(Amazon Bedrock、RAGアーキテクチャ)、エージェント型AI、基盤モデルとLLM、従来の機械学習と生成AIにおける責任あるAIが追加されました。ドメインの構成は変わらず、配点はモデル開発が26%から24%、デプロイとオーケストレーションが22%から24%に変わります(AWS公式の試験ページ・MLA-C02試験ガイド、2026年10月19日確認)。
前提条件・推奨経験はありますか？+
受験の前提条件はありませんが、公式の試験ガイドでは、Amazon SageMakerをはじめとするAWSサービスを使った機械学習エンジニアリングの経験1年以上と、バックエンド開発・DevOps・データエンジニア・データサイエンティスト等の関連職務の経験1年以上を、対象受験者の目安としています。
