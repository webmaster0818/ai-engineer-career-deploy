エンジニア向けスカウトサービス5社｜スカウトの送り手と料金を公式情報で比較

ITエンジニアが登録すると企業などからスカウトが届く転職サービス5社（Findy・Forkwell・レバテックダイレクト・リクルートダイレクトスカウト・ビズリーチ）について、スカウトを送るのは誰か、料金、各社が公表している数値を、公式サイトで同じ日（2026年11月17日）に確認して並べました。

対象：ITエンジニア向けのスカウト型転職サービス掲載5社（順位付けなし）

エンジニア向けのスカウトサービスは、スカウトを送ってくる相手で2つに分かれます。Findy・Forkwell・レバテックダイレクトは企業から直接スカウトが届く仕組みで、リクルートダイレクトスカウトとビズリーチは、企業に加えて転職エージェント（ヘッドハンター）からもスカウトが届きます（2026年11月17日に各社公式サイトで確認）。

料金は、5社とも求職者が無料で利用できます。ビズリーチのみ一部の機能が有料会員向けで、公式FAQでは「ご自身で申し込まない限り、登録時などに自動的に料金が発生することはありません」と案内しています。

掲載は5社で、順位付けは行っていません。当サイトで個別ページを設けているスカウト型のサービスから選んでいます。各社の許可番号・運営会社などは、各社の個別ページに掲載しています。

エンジニア向けスカウトサービスの選び方

  1. 1. 企業と直接話したいか、エージェントにも相談したいかで選ぶ

    企業から直接スカウトが届くサービス（Findy・Forkwell・レバテックダイレクト）は、企業の担当者と最初から話せます。エージェントからのスカウトも受け取りたい場合は、リクルートダイレクトスカウトやビズリーチが対象です。

  2. 2. プロフィールと職務経歴を具体的に書く

    スカウトは登録情報をもとに送られます。使っている言語・フレームワーク、担当した工程、チームでの役割を具体的に書くと、条件の合うスカウトが届きやすくなります。Findyは GitHub との連携にも対応しています。

  3. 3. スカウト型と紹介型の転職エージェントを併用する

    スカウトを待つだけでは、応募先の幅が登録情報に左右されます。担当者が求人を提案する転職エージェントと併用し、AI職など希望分野の求人を両方の経路で確認すると、比較しやすくなります。

よくある質問

Q1.エンジニア向けのスカウトサービスにはどんな種類がありますか？↓

A.企業から直接スカウトが届くサービス（Findy・Forkwell・レバテックダイレクトなど）と、企業に加えて転職エージェント・ヘッドハンターからもスカウトが届くサービス（リクルートダイレクトスカウト・ビズリーチなど）があります（2026年11月17日に各社公式サイトで確認）。

Q2.スカウトサービスの利用に費用はかかりますか？↓

A.本ページの5社は、いずれも無料でスカウトの受信・返信ができます。ビズリーチは一部の機能が有料会員向けですが、自分で申し込まない限り料金は発生しないと公式FAQで案内しています。

Q3.スカウトに返信すると、必ず選考に進みますか？↓

A.サービスによって異なります。リクルートダイレクトスカウトは、返信後に企業担当者またはエージェントとの面談を必ず受けられると案内しています。レバテックダイレクトは、全スカウトメールの95%が面接または面談を確約したスカウトと公表しています（2026年1〜3月実績）。

Q4.スカウトサービスでAIエンジニアの求人は見つかりますか？↓

A.スカウトは登録情報をもとに送られるため、機械学習・データ分析の経験や使用技術をプロフィールに具体的に書くことが前提になります。AI関連の求人件数は、Forkwell・Findyなど各社の個別ページで公式検索の件数を掲載しています。
