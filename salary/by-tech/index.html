（目安: +3〜4ヶ月）

4

+ AWS/GCP ML Services

（目安: +2〜3ヶ月）

+ LLM / RAG / LangChain

（目安: +2〜3ヶ月）

よくある質問

Q.求人数が多い技術キーワードはどれですか？

求人ボックスの掲載件数（2026年10月20日時点）では、Python 187,281件、RAG 13,462件、PyTorch 2,926件、TensorFlow 2,228件、LangChain 1,444件、Hugging Face 140件です。件数はキーワードを含む求人の検索結果件数で、重複掲載を含みます。技術スタック別の平均年収は、出典を確認できる統計がないため当サイトでは掲載していません。

Q.Pythonだけでも転職できますか？

Python + SQL + scikit-learn があれば、データアナリスト・ジュニアデータサイエンティストとしての転職は可能です。モデル開発や生成AIの求人に応募する場合は、PyTorchやLLM関連の知識が求人票の要件に含まれることがあります。

Q.LLMエンジニアになるには何から始めるべきですか？

Python基礎（1〜2ヶ月）→ OpenAI/Claude APIの利用（2〜4週間）→ LangChain・RAGの構築（1〜2ヶ月）の順に進める方法が効率的です。Web開発の経験がある方は、特に習得が早い傾向があります。GeeklyやSymbioriseがLLMエンジニア向けの求人を多数保有しています。

Q.AWS・GCPの認定資格は取るべきですか？

AWS Certified Machine Learning Engineer – Associate・Google Cloud Professional Machine Learning Engineerなどの認定は、クラウド上で機械学習を実装・運用するスキルを示す材料になります（AWS Certified Machine Learning – Specialtyは2026年3月31日を最終受験日として廃止されました（AWS公式））。ただし、資格より実務経験やポートフォリオのほうが重視されることも多いため、実装経験と並行して取得することをおすすめします。

Q.技術スタック別の転職に強いエージェントはどこですか？

LLM/生成AI系はGeekly・Symbiorise、深層学習系はGeekly・レバテックキャリア、クラウドML系はウィルオブテック・レバテックキャリア、入門（Python/scikit-learn）はレバテックキャリア・マイナビITエージェントが強みを持っています。

Q.技術スタックの習得には独学とスクールのどちらがよいですか？

学習時間を確保できる場合は、独学（Kaggle Learn・fast.ai・Udemy）の費用対効果が高くなります。ただし、学習の方向性に迷いやすく、ポートフォリオ作成へのフィードバックを得にくい面があります。3〜6ヶ月で集中的に転職を目指す場合は、AI特化スクール（受講後にエージェントの紹介を受けられる場合もあります）が有効なこともあります。
