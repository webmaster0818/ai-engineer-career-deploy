主要企業のAIエンジニア求人実態レポート【2026年版】

本レポートの要点（2026年・公式採用ページ集計）

AI採用で知られる主要74社の公式採用ページを2026年10月〜11月に確認したところ、AI/ML求人の件数を確認できた27社だけで合計179件のAI・機械学習エンジニア公開求人を確認しました。件数が最も多いのはフィックスターズの16件です。件数の定義（検索語・職種区分）は企業ごとに異なるため、企業間の単純な比較には使えません。

本レポートは、AI採用で知られる主要74社の公式採用ページを直接集計し、AI・機械学習エンジニアの公開求人の実態をまとめた年次レポートです。各社の採用システムから取得した一次情報にもとづいています。

集計方法は本ページ末尾の「調査方法」をご覧ください。求人数は変動します。応募時は各社公式の最新情報をご確認ください。本レポートは月次で更新します。

企業別の注記

フィックスターズ

  • ・AI/ML関連求人の件数は、2026年11月26日に公式採用ページ（HERP）の求人一覧に掲載されていた47件のうち、職種名にAIまたはLLMを含む求人を当サイトで数えたものです。一覧にはグループ会社Fixstars Amplifyの求人3件も含まれます。
  • ・AI関連以外では、NVMe SSDファームウェア開発・AD/ADAS向け画像処理・組込みC/C++・数理最適化の高速化・暗号アルゴリズム開発などのエンジニア求人が掲載されています。

ブレインパッド

  • ・【重要】ブレインパッドは2026年3月に株式を非公開化しています（公式の会社概要・沿革）。掲載している全社平均761万円は、非公開化前の2025年6月期有価証券報告書の値です。
  • ・HRMOS全53件中、データサイエンティスト4件・機械学習エンジニア3件・AIビジネスコンサルタント・AIエージェントサービスのエンジニア・Forward Deployed Engineer（AIエージェント社会実装）・生成AI活用プロダクト開発2件・データ基盤3件（データプラットフォームテックリード2件・データ基盤開発PM候補）を当サイトで集計した値です（2026年10月31日確認）。

DeNA

  • ・公式採用ページの求人一覧の掲載は71件（キャリア登録2件を含む）です。職種グループ表示では、データ・AIが12件、Engineerが31件です。データ・AIの12件は職種グループの表示件数で、M&A・投資・営業の4件（Business）とキャリア登録1件を含みます（2026年11月22日確認）。
  • ・Applied AI Engineer の求人票の月給は407,500円〜1,105,000円（勤務体系によって変動・選考を通じて決定）です。
  • ・新卒のAIスペシャリスト職（2027年4月入社など）は、標準年収7,000,000円〜（月給×12か月＋年2回の賞与）と公式の募集要項に記載されています。年俸は選考を通じて決定されます。

  • ・職種名にAIを含まないデータエンジニア職（データエンジニア・PL・PM）が別に3件掲載されています。

調査方法

各社の公式採用サイト・採用システム（HRMOS / HERP / workable / 公式求人ページ等）から、「machine learning / 機械学習 / データサイエンティスト / AI」に該当する公開求人を2026年10月〜11月に確認しました（企業ごとの確認日は表に記載）。職種名は実際の募集タイトルを採用しています。公式採用ページで職種名を確認できなかった企業は、表に掲載していません。

公式採用ページで件数の表示を確認できなかった企業は「件数の掲載なし」とし、推測値は掲載していません。各社の事実は公式情報のみを出典としています。
